| D-022 | 2026-11-26 | accepted | Claim-parser lexicon rules (UC-041, `config/lexicon.yaml`), which decide how SRQ3 counts LLM claims: (1) by default every quantifier phrase maps to the **core** set few / about half / most ("very few / hardly any / almost no" → few, "almost all / nearly all / almost always" → most); the extended words almost_none / almost_all are used only for the UC-054 ablation (`load_lexicon(quantifier_set="extended")`). (2) Phrases that match no single vocabulary word count as `unverifiable` with no summarizer, instead of being guessed: bare "delayed / delay(s) / behind schedule" (any delay vs. `late` = 3–10 min); qualified forms keep their word ("slightly delayed" → slightly_late, "badly / severely … delayed" → very_late). (3) Bare time words ("morning(s)", "evening(s)", "rush hour", "peak") and hub / line mentions mean the question's own segment and add no restriction; only explicit phrases select a time band ("morning / evening peak or rush (hour)", "early morning", "late evening", "night", …). (4) Negation anywhere in a sentence → `unverifiable`. (5) "usually / generally / typically" → most. (6) Bare percentages → `unverifiable`. | PM review of #40: these mappings set how often an LLM claim scores false (H3a, H3c), so they must not add a bias of their own. |
| D-023 | 2026-11-26 | accepted | SRQ3 claim-checker semantics (UC-042, `llm/checkers.py`, methods §6). Crisp checker (Stat-to-Text style, D-012): each row gets exactly one crisp word from the 0.5-cut partition of the vocabulary, i.e. the boundary between neighbouring words is the crossover (c + d)/2 of the upper word's falling ramp, except two boundaries fixed by definition: on_time | slightly_late at the SBB 3-min rule (`crisp_baseline.punctual_threshold_minutes`, D-007) and missed = slack < 0. Result: on_time < 3, slightly_late [3, 4), late [4, 9), very_late ≥ 9 min; missed < 0, tight [0, 1.5), comfortable ≥ 1.5 min. NaN = unknown and dropped; cancelled connections are encoded by the caller as slack −∞ and count as missed. This crisp *checker* differs by design from the SRQ2 crisp *baseline* (official punctual / not punctual at 3 min). | PM review of #43: the crisp word rule determines H3c; recorded so the SRQ2/SRQ3 difference is explicit. |
